# 楚风礼赞

iOS 开发。业务代码在公司 GitLab，GitHub 上公开的不多。

臭看动漫的，偶尔做点同人周边。头像是《學園少女突襲者》的千年 夕依，游戏已经关服了。

## 开源

- [BoroAni](https://github.com/chufeng/BoroAni)  
  为老款 Android (android5+)电视和盒子做的轻量追番应用，用遥控器就能找番、选集和播放。

- [astrbot_plugin_bili_resolver](https://github.com/chufeng/astrbot_plugin_bili_resolver)  
  AstrBot 插件：解析群聊里的 B 站链接/小程序卡片，回视频摘要和封面。

- [ai-video-workspace](https://github.com/chufeng/ai-video-workspace)  
  用 AI 搭的视频工作流：剧本、分镜和项目状态用 Git 同步，成片和大文件不进仓库。

- [NewiOSOfQFNU](https://github.com/chufeng/NewiOSOfQFNU)  
  大学时写的曲园教务 iOS 客户端，当黑历史开源着。

## Tech Stack

- **Mobile:** Objective-C, UIKit, Kotlin
- **Backend & Automation:** Python
- **Other:** TypeScript, Git, AI Agents, 一点 TypeScript
